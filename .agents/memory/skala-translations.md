---
name: SKALA translations
description: Standing instruction to translate new SKALA site additions into all supported languages.
---

Translate every new site addition into all languages the site supports and check the translations for errors.

**Why:** the user asked.

**How to apply:** Include all supported locales in the same change whenever adding user-facing site content.

Default-language intent: the user wants Slovak at startup, with Czech for Czech visitors and manual language switching available.

**Why:** The user wants the site to suit Slovak and Czech audiences rather than start in Ukrainian.

**How to apply:** Use the preferred browser language as a privacy-preserving approximation (Czech → Czech, otherwise Slovak), not a claim of physical location. Honor a visitor's explicit saved language choice.
